# 婚礼排桌系统 PRD

> 项目名称：wedding-feast  
> 项目类型：婚礼宾客管理与可视化排桌工具  
> 当前版本：MVP v0.1  
> 技术栈：Vue 3 + TypeScript + Nuxt + Supabase + Pinia + Tailwind CSS + Motion + Vercel  
> 更新时间：2026-09-04

---

# 1. 项目背景

婚礼筹备过程中，宾客名单管理和婚宴桌次安排通常需要通过 Excel、纸质名单或聊天记录完成。

传统方式存在以下问题：

- 宾客信息分散，不方便统一管理

- 容易遗漏宾客或重复统计人数

- 无法直观查看宾客是否已经安排座位

- 调整桌次时需要频繁修改 Excel

- 无法直观模拟婚宴现场布局

- 桌子、舞台、T 型台的位置难以统一规划

本项目旨在提供一个简洁、现代、可视化的婚礼排桌工具。

用户可以完成：

1. 管理婚礼宾客名单

2. 查看宾客人数统计

3. 创建婚宴桌子

4. 自由布置婚宴现场

5. 拖拽宾客安排座位

6. 查看未安排座位的宾客

7. 保存婚宴桌次布局

第一阶段只聚焦两个核心模块：

> **宾客名单**
>
> **桌次安排**

其他功能后续逐步增加。

# 7. 宾客统计

页面顶部展示统计信息。

## 7.1 出席总人数

计算：

```text
所有成人宾客
+
所有儿童人数
```

默认每个宾客本人算一名成人。

如果存在同行人数：

```text
总成人数
=
宾客数量
+
同行成人数量
```

---

## 7.2 大人数量

计算：

```text
宾客本人
+
同行人数
```

---

## 7.3 儿童数量

计算：

```text
所有宾客 children_count 之和
```

---

## 7.4 男方 / 女方人数

按照宾客所属统计：

```text
男方

女方
```

第一版按照：

```text
宾客本人所属
```

进行统计。

# 8. 宾客字段

## 8.1 基础字段

| 字段     | 类型   | 必填 | 说明               |
| -------- | ------ | ---- | ------------------ |
| 姓名     | string | 是   | 宾客姓名           |
| 分类     | string | 是   | 亲戚、朋友、同学等 |
| 所属     | enum   | 是   | 男方 / 女方        |
| 联系电话 | string | 否   | 手机号码           |
| 同行人数 | number | 是   | 同行成人数量       |
| 儿童人数 | number | 是   | 儿童数量           |
| 备注     | string | 否   | 备注信息           |

# 48. 产品核心原则

整个项目开发过程中遵循以下原则：

## 1. 先完成核心功能

不要过早增加：

```text
登录

多人协作

AI

复杂权限
```

---

## 2. 所有操作尽可能直观

用户应该：

```text
看到
↓
理解
↓
操作
```

尽量减少复杂配置。

---

## 3. 桌次页面优先视觉体验

桌次安排页面是整个产品的核心。

重点投入：

```text
Canvas

拖拽

圆桌

座位

动画

交互反馈
```

---

## 4. 数据结构必须为未来扩展留空间

虽然 MVP 功能简单，但数据库需要支持未来：

```text
多个婚礼

多个用户

多人协作

更多现场元素
```
