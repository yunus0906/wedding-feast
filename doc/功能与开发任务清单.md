# wedding-feast 功能与开发任务清单

## 1. 功能清单

### 1.1 宾客名单

- 新增宾客
- 编辑宾客
- 删除宾客
- 姓名搜索
- 人数统计
- 男方 / 女方统计
- CSV 导入
- CSV 导出

### 1.2 桌次安排

- 新增圆桌
- 编辑桌名与容量
- 删除桌子
- 拖拽移动桌子
- 添加舞台
- 添加 T 型台
- 未入座宾客列表
- 点击宾客安排座位
- 点击座位快速安排
- 移除宾客座位
- 保存布局状态

### 1.3 UI 风格

- 漫画红、英雄蓝、警示黄作为主视觉色
- 粗黑边框
- 分格式布局
- 纸张底色
- 按钮、卡片、画布具备漫画书式强轮廓

- Supabase 表结构与同步逻辑保留为下一阶段任务
- UI 已按漫画书风格建立基础视觉系统
